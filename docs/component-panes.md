# 组件窗格

Tab 的分屏树由通用 `Pane` 容器组成，每个容器持有一个 `paneContent`。内置内容包括终端、文件浏览器、只读 Diff 和网页浏览器。容器管理分屏、焦点、放大、位置、关闭入口和持久身份；组件管理渲染、工具栏、状态快照及资源释放。

## 使用

- View 菜单和命令面板提供「打开终端窗格」「新建文件窗格」「打开 Diff 窗格」「打开浏览器窗格」。
- `⇧⌘E` 或标题栏文件按钮在当前窗格旁打开文件浏览器；焦点位于文件或 Diff 窗格时，关闭该窗格。
- `⌘D` / `⇧⌘D` 向右 / 向下分屏，新窗格沿用当前组件类型。新文件窗格具有独立的目录、筛选、文件选择及请求。
- `⌘W` 关闭当前窗格；`⇧⌘W` 关闭整个 Tab，沿用终端会话的现有关闭语义。放大、均分与方向键焦点导航适用于混合分屏。
- 点击终端文件链接，在旁边打开文件窗格；点击 Git 摘要，在旁边打开 Diff 窗格。

文件与 Diff 初次打开时继承来源主机和目录，此后不跟随其他窗格的焦点或工作目录跳转。「回到初始目录」返回打开时的目录。来源会话 ID 单独保存在组件内，本轮 Diff 只跟随该来源会话的轮次；来源关闭后保留最后取得的轮次身份，不猜测其他会话。

文件窗格初始占左右分屏较大的空间；内容区宽度不足 720pt 时，当前选中的文件或 Diff 窗格单独显示，底层分屏树和比例保留。放宽窗口后恢复分屏；也可以主动放大窗格。文件树请求、代码预览和滚动状态在切换 Tab 后继续保留，关闭窗格时取消其自己的任务。

## 状态和生命周期

`Pane.Key` 是独立于会话 SID 和浏览器 Web ID 的持久身份。布局记录内容类型、分屏比例、焦点、放大状态和组件快照：终端保存会话及尺寸，浏览器保存 URL 和 Web ID，文件 / Diff 保存初始目录、当前目录、筛选、文件选择、树宽度、比较范围和来源会话 / 轮次。旧布局缺少 `kind` 时仍按已有 SID / browser 字段恢复；旧全局文件工作台开关在首次显示时迁移为文件窗格。

会话轮询、远端输入所有权、会话通知和 Agent 恢复只处理终端组件。关闭文件 / Diff 不结束来源会话，关闭浏览器只销毁自身 WebView 与端口转发。退出 GUI 通过统一组件清理入口释放视图和请求，终端继续沿用脱离连接并保留会话的行为。不支持的组件类型保留状态并显示提示，不创建替代 shell。

终端重启、清屏和终端历史只对终端生效，其他组件聚焦时从命令面板隐藏。`⌘F` 根据焦点搜索终端或文件预览，没有预览时聚焦文件筛选框。

## 隔离验证

```sh
GOWORK=off go test . -run 'TestComponentPanes|TestMixedComponent|TestUnsupportedComponent|TestBrowser|TestDesktopFile|TestTurnDiff' -count=1
GOWORK=off go test ./...
GOWORK=off go vet ./...
```

测试使用自己的服务、shell、临时目录和远端连接替身，验证多组件布局、独立状态、持久身份、异步恢复、远端主机绑定以及原终端进程保持不变。
