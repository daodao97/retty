# Git 项目与轮次审阅

窗格顶部显示当前分支、相对 HEAD 的增删行数及 merge/rebase 等状态。点击摘要，在终端旁打开只读 Diff 窗格，与终端共用分屏树。窗口较窄时单独显示选中的文件 / Diff 窗格；关闭后回到原终端，不创建或结束会话。可打开多个独立的文件 / Diff 窗格，各自保留目录、比较范围与文件选择，详见 [组件窗格](component-panes.md)。

侧边栏活动 Tab 保持原来的会话顺序，不额外显示项目文件夹标题。底部“项目会话”默认收起，点击标题展开或再次收起；展开后才读取和刷新本机历史。本机 Agent 历史按 Git common directory 归组，同一仓库位于不同目录的 linked worktree 属于同一项目，但保留原工作目录、账号配置、分支与真实对话身份，恢复会话仍进入原 Worktree。历史归组不会改写已保存 Tab 顺序或 PTY 身份。

设置 → 外观 → **Git 分支与变更** 可以停止后台状态查询。查询在后台执行，最多四个并发请求、256 个状态缓存项；本机历史项目身份缓存最多 512 个目录。远端始终通过其独立、已认证文件通道读取，不将远端路径退回本机解析。

## 比较范围

- **本轮**：比较 Agent 开始本轮时的工作区与请求审阅时的快照，排除开始前已存在的脏改动和未跟踪文件。未跟踪文件若在本轮被修改或新建，仍会列出。
- **未提交**：比较当前文件与 HEAD，包括暂存和未暂存改动，以及未跟踪文件。
- **整个分支**：比较默认分支共同祖先与当前工作区，包括本分支已提交的改动。优先使用 origin 的默认分支；没有该记录时识别本地 main/master。

选择文件查看只读 Diff，使用刷新按钮取得新的比较。打开的轮次/分支预览绑定不可变的快照对象：Agent 继续修改时，不会把一份 Diff 的前半和后半混在一起。新的轮次身份到达时自动清空上一轮比较并重新加载；短暂未完成的基线最多自动重试两次。文件窗格也提供相同的比较范围。

多个 Agent 或用户共同修改同一个 Worktree 时，**本轮**表示这个时间范围内的工作区变化，不保证逐项归属于该 Agent。使用独立 Worktree 可以分开这些变化。本版不提供回退或写入文件的按钮，也不修改 Git index。

## 基线与兼容性

基线由拥有 PTY 的服务在接受 Agent `UserPromptSubmit` 事件时记录；Codex 使用已确认的根线程生命周期事件和真实 turn ID，临时线程不建立基线。重复 turn ID 不重新记录。仅打开 GUI 或发现 Agent 正在运行，不会猜测一份起始快照。

记录最多使用两秒，失败不阻止 Agent 继续工作。查看端必须提交服务广播的本轮身份；身份不同、工作区切换、记录失败或基线缺失时显示原因，绝不把上一轮快照当作本轮。`hello.turn_diff` 表示服务支持该能力。

旧 PTY 服务继续运行原任务。只更新 GUI 可启用 Git 摘要、归组和分支比较，但不会让旧服务追溯记录轮次；待任务结束并安全更新服务后，从新一轮开始提供本轮基线。远端文件功能需由对应 GUI 桥接或 CLI 网关支持，不为启用功能重启真实服务。

## 存储与限制

快照保存在应用数据目录的 `git-snapshots/`，按仓库隔离为私有 Git 存储。它使用自己的 index 路径、对象和引用，原仓库的 index、对象及引用保持不变。记录过程不调用模型或上传外部服务；远程审阅仅通过现有认证连接按需读取变更。新对象通过 raw fast-import 写入，保留 CRLF、可执行位、文件名和符号链接本身，不跟随链接读取目标。

所有查询禁用外部 diff、textconv、fsmonitor、clean/process 过滤器以及可选索引锁。源仓库只执行读取；不会运行项目脚本来取得状态或快照。

单次快照最多记录 5000 个文件、32MB 内容，单文件最多 4MB；不会递归子模块或读取设备文件。超出范围显示“部分结果”，被略过的文件不会被伪装成删除。Git 命令输出上限为 4MB。普通未提交状态的行数汇总另有文件数和字节数限制，达到限制时明确标记“部分”。

## 隔离验证

`internal/gitstate` 验证脏 index、独立元数据目录、unborn/detached、linked worktree、特殊文件名、CRLF、符号链接、大文件、原仓库不变和过滤器不执行。`internal/rex` 用自有 PTY 验证无 GUI 时记录、重复事件与轮次身份。文件与远端测试验证不可变 Diff、路径边界，以及 daemon 不可用时仍由桥接读取。桌面测试验证终端旁审阅、范围切换、缺失基线、窄窗口和关闭恢复。

所有测试使用临时仓库、状态目录、socket 与 shell，不读取真实任务内容或向真实 Agent 输入。
