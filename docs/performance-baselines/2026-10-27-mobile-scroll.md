# 手机长对话滚动调查（尚未完成真机验收）

用户反馈 `chatgpt-share-server-deploy` 长对话在局域网内仍然滚动卡顿。
只读检查确认该会话启用了 alternate screen、SGR mouse 和鼠标追踪。
其累计 PTY 输出约 30 MB，但当前 48×33 画面的有界快照只有约 2.3 KB；
累计输出不能解释为每次滚动的网络传输量。

此时滚动由 Codex 处理：手机将滚轮报告发给源程序，再接收权威画面。
局域网可以降低网络等待，不能消除源程序重绘、快照应用和手机呈现的耗时。
`PreferScreenSync(false)` 的参数表示 `inputOnly=false`，仍然启用画面同步。

## 已验证的改动

原先跨过 N 行会调用 N 次原生编码器，并逐次入队；`rex.Stream.Write`
将每次写入包装为独立的 `screenInput` 消息。现在同一事件内的重复报告只
编码一次，复制到一个缓冲区后入队。没有增加延迟定时器，没有丢弃滚轮报告，
跨事件的输入顺序、坐标、方向、总距离及小数行累积保持不变。
鼠标报告和 mode 1007 的箭头报告均覆盖此路径。

回归样本包含向上 32 行、向下 64 行及随后键入的文字，队列写入从 97 次
减少为 3 次。SGR、旧鼠标编码、普通及 application cursor 箭头编码的完整
字节串分别与固定预期一致；新增测试在改动前因写入次数断言失败。

`internal/terminal`、`internal/rex` 和主包合计 779 项测试通过；8 项相关
race 测试、terminal vet、`git diff --check` 和 MyGo 依赖检查通过。

Apple M3 / darwin arm64 / Go 1.27.3，三个同进程重复样本的中位数：

| 单事件行数 | 改前编码耗时 | 改后编码耗时 | 改前分配次数 | 改后分配次数 |
| --- | ---: | ---: | ---: | ---: |
| 3 | 3.870 μs | 1.551 μs | 34 | 16 |
| 32 | 41.228 μs | 1.589 μs | 295 | 16 |
| 128 | 156.339 μs | 1.694 μs | 1159 | 16 |

命令：`GOWORK=off GOTOOLCHAIN=go1.27.3 go test ./internal/terminal -run '^$' -bench '^BenchmarkRemoteScrollBurst$' -benchmem -count=3`。
原始数据位于 `.mygo/performance/long-chat-scroll/{before,after}-bench.txt`。
基准只测滚动编码与入队，未运行网络、Codex 重绘或手机 GPU；同进程重复
不能作为完整应用的三轮独立性能基线，也不能解释为手机帧率改善。

## 反复改变方向的后续调查

用户反馈首轮安装后更流畅，但反复上下滑动仍然卡顿。第二次只读采样确实
覆盖了约 5 秒滚动：目标会话输出增加约 599 KB，活跃的半秒窗口中源
Codex CPU 约为单核的 2.3%～5.7%。这不足以证明重绘完全没有延迟，但
未看到源 Codex 持续占满 CPU。原始计数位于
`.mygo/performance/scroll-reversal/passive.json`。

后续修复针对跨触摸事件的积压：输入 worker 过去一次只取一条，即使
写入期间已经排入很多后续事件，也逐条调用传输。现在立即取出已有积压，
合并为最多 32 KiB 的写入；没有等待凑批的定时器，没有按净位移消除方向
变化，也没有丢弃滚轮或键盘输入。单条超长粘贴保留原传输分块行为。
同时正确完成短写，并在无进展、非法写入计数或写入错误时关闭输入队列。

短写和失败停止有独立回归；改动前这些测试分别复现拆散积压、丢失短写

## 手机正文的短过渡

继续优化时先验证了跨快照复用行布局。软件基准中 ASCII 帧中位数约
429→406 μs、Unicode 帧约 422→411 μs；三个同进程样本不足以认定稳定
CPU 改善。单独缓存不作为解决顿感的结论；它用于安全保留不可变的上一帧，
让已确认的正文行位移补上本地中间位置。

手机启用 `Options.SmoothScroll`，桌面默认路径不变。近期精确滚动输入
之后，只有与上一帧连续行的实际渲染签名精确匹配时，才对识别出的正文
区域做 32 ms 过渡。固定输入区、页头/页脚不整体平移。出现同分候选、
不匹配内容、大跳转、选区、图片、搜索、输入法组合、重排或几何变化时，
直接显示权威画面。新画面不排队等待旧过渡，反向输入取消旧运动；点按
仍移动的正文会先停止过渡并消费该次点击，避免打开相邻行链接。

渲染签名包括实际样式、组合字符、宽字符、背景和选择范围，不依赖 Reset
可能复用的原生样式/字形 ID。缓存上限为 128 行、1 MiB；过渡只保留
上一帧的共享不可变行，完成后释放引用，空闲时不维持动画循环。

测试用虚拟时钟校验中间像素位置、固定区不动、结束时与无过渡渲染逐像素
一致，并覆盖新帧中断、方向反转、误点击保护、样式/调色板/字体/组合字符
变化和缓存上限。1054 项全量测试、20 项相关 race、普通及生产 vet 通过。
启用该选项后的滚轮输入仍与固定字节预期完全一致。
